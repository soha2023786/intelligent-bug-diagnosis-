# M1.4 — Historical Defect Knowledge Base

## Project Title

**Creation of Intelligent Bug Diagnosis Platform with Fix Recommendation Assistance**

---

## 1. Objective

The objective of the Historical Defect Knowledge Base is to create a searchable collection of historical software defects that can be used to identify bugs similar to a newly submitted defect.

The knowledge base supports the Retrieval-Augmented Generation (RAG) pipeline by providing relevant historical defect information to the AI diagnosis layer.

---

## 2. Historical Defect Sources

The planned knowledge base uses publicly available historical bug datasets from:

- Mozilla
- Apache
- Eclipse

A small sample dataset is currently included in the repository for development and testing.

The full public datasets will be incorporated after verifying their availability, format, and licensing conditions.

---

## 3. Knowledge Base Processing Pipeline

The historical defect processing pipeline is:

```text
